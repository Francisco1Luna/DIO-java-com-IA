# 🚀 Bootcamp Itaú - Java com Inteligência Artificial

Este repositório contém todo o meu progresso, códigos, projetos práticos e desafios de código desenvolvidos durante o bootcamp **Itaú - Java com Inteligência Artificial**, oferecido pela **Digital Innovation One (DIO)** em parceria com o **Itaú**.

---

## 📌 Sobre o Bootcamp

O bootcamp aborda desde os fundamentos da linguagem Java até conceitos avançados de Orientação a Objetos, ecossistema Spring Boot e integração com Inteligência Artificial, aplicados ao contexto de tecnologia e sistemas financeiros.

* **Carga Horária:** 45 horas
* **Nível:** Básico ao Avançado
* **Plataforma:** [Digital Innovation One (DIO)](https://www.dio.me/)

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** Java (JDK 17+)
* **IDE:** JetBrains IntelliJ IDEA
* **Controle de Versão:** Git & GitHub
* **Frameworks & Libs:** Spring Boot, JUnit (testes)
* **Conceitos:** Programação Orientada a Objetos (POO), Estruturas de Dados, APIs REST, Inteligência Artificial aplicada
